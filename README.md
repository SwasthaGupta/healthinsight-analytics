# HealthInsight: Healthcare Data Quality & Population Health Analytics

## Overview

HealthInsight is an end-to-end healthcare analytics portfolio project built using Python, SQL, and Power BI. It uses synthetic healthcare records to analyze healthcare utilization, recorded conditions, and data quality.

The project demonstrates data ingestion, exploratory analysis, validation checks, SQL analytics, and interactive business intelligence dashboards.

## Objectives

- Inspect and validate healthcare datasets.
- Identify missing values, duplicate identifiers, invalid date ranges, and broken record relationships.
- Analyze patient demographics, encounter utilization, recorded conditions, and encounter costs.
- Present analytical findings through interactive Power BI dashboards.

## Technology Stack

- **Python:** Pandas and data validation
- **SQL:** SQLite, aggregations, joins, and analytical queries
- **Power BI:** Interactive dashboards and filtering
- **Git/GitHub:** Version control and project documentation

## Dataset

The project uses synthetic healthcare records generated by Synthea.

Dataset source: https://synthetichealth.github.io/downloads.html

The dataset is synthetic and does not represent real patient outcomes or real-world healthcare prevalence.

## Project Workflow

1. Inspect CSV files and document their schemas.
2. Run Python-based data-quality checks.
3. Load selected healthcare tables into SQLite.
4. Execute SQL queries for patient demographics, encounter utilization, recorded conditions, costs, and data quality.
5. Export analytical results for visualization.
6. Build Power BI dashboards.

## Power BI Dashboards

### 1. Healthcare Overview
Summarizes patient demographics, healthcare encounter volume, monthly utilization, and recorded encounter costs.

### 2. Data Quality Dashboard
Visualizes validation findings and missing-value patterns.

### 3. Population Health
Explores frequently recorded conditions and healthcare utilization with year-based filtering.

## How to Run

1. Download the synthetic CSV dataset from the official Synthea source.
2. Place the required CSV files inside `data/raw/`.
3. Create and activate a Python virtual environment.
4. Install dependencies:

   `pip install -r requirements.txt`

5. Run the inspection and data-quality scripts.
6. Run the SQLite database loader.
7. Execute the SQL analytics script.
8. Open the Power BI report in Power BI Desktop.

## Limitations

- The dataset is synthetic and cannot establish real-world clinical outcomes.
- Data-quality findings depend on the validation rules implemented.
- Encounter costs reflect source dataset fields and should not automatically be interpreted as actual paid amounts.
- The project is an independent portfolio prototype, not a production healthcare platform.
